# Cafnet Backend

Backend service and domain architecture for Cafnet.

## Structure
- `docs/` - Complete domain specifications, architecture documentation, data invariants, and state machines.
- `server.js` - API server entry point.
- `package.json` - Node.js dependencies and scripts.

## Getting Started

```bash
npm install
npm run dev
```

For domain specifications and database models, refer to [docs/README.md](docs/README.md).
